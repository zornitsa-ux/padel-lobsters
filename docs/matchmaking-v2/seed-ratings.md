## Method notes

- **Capped deltas only.** A player whose event delta exceeded ±0.30 moved 0.30 and
  the remainder was withheld — exactly as live. Seeding does not retroactively
  approve remainders; that is what the review queue is for.
- **No sigma inactivity inflation.** `inflateForInactivity` is not applied: the
  live path never calls it, so applying it while seeding would invent a policy no
  later event maintains. Worth revisiting as its own decision.
- **Skipped rows.** Zero-total matches, matches with a player missing from the
  roster, and matches with the same player twice are skipped, not fatal.
- **Players with no match history get no row** — a null `mm_rating` already means
  "fall back to the playtomic prior", which is the correct seed for them.
